# Project Diagrams — Free-Tier AWS Version

This folder contains text diagrams that can be pasted into the written report or converted into PNG screenshots for the presentation.

## Included Diagrams

1. `architecture-diagram.txt`  
   Shows GitHub Actions, ECR, EC2, Docker Compose, PostgreSQL container, IAM, SSM, and CloudWatch.

2. `data-flow.txt`  
   Shows both the user request flow and the CI/CD deployment flow.

3. `threat-model.txt`  
   Lists key assets, threats, and security mitigations.

4. `cicd-pipeline-flow.txt`  
   Shows the CI/CD stages from push to deployment and rollback.

## Recommended Report Captions

- **Figure 1:** Free-tier AWS architecture for the secure CI/CD task manager project.
- **Figure 2:** Application request and CI/CD deployment data flow.
- **Figure 3:** Threat model mapping assets, risks, and mitigations.
- **Figure 4:** GitHub Actions DevSecOps pipeline with rollback.
