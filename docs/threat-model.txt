THREAT MODEL — FREE-TIER AWS VERSION

Assets:
- Source code repository
- GitHub Actions workflow
- Docker image in Amazon ECR
- EC2 instance
- PostgreSQL Docker volume
- JWT signing secret generated on EC2
- CloudWatch logs
- IAM roles and policies

Threats and mitigations:

1. Exposed secrets in code
   Threat: Developer accidentally commits passwords or tokens.
   Mitigation: Gitleaks runs in CI/CD before image build and deployment.

2. Vulnerable container image
   Threat: Base image or Python dependency has known HIGH/CRITICAL CVEs.
   Mitigation: Trivy scans the image and blocks deployment on HIGH/CRITICAL findings.

3. Over-permissive AWS credentials
   Threat: CI/CD role can modify unrelated AWS resources.
   Mitigation: GitHub OIDC role is scoped to the repository/branch and limited to ECR push, SSM deployment command, and reading project SSM parameters.

4. SSH key exposure
   Threat: Private SSH key leaks from student machine or GitHub secret.
   Mitigation: Deployment uses AWS Systems Manager Run Command instead of SSH.

5. Public database exposure
   Threat: Database is reachable from the internet.
   Mitigation: PostgreSQL runs as a Docker container without publishing port 5432 on EC2. Only the Flask container accesses it over the Docker network.

6. Application endpoint abuse
   Threat: Public app port receives excessive requests.
   Mitigation: Flask-Limiter applies API rate limiting. Security Group can restrict port 5000 to instructor/student IP for demo.

7. Broken deployment
   Threat: New image starts but application/database health fails.
   Mitigation: /health endpoint checks app and database connectivity. CI/CD triggers rollback on failure.

8. Sensitive logs
   Threat: Logs may expose credentials or private data.
   Mitigation: Application uses structured logs for request metadata only; secrets are generated on EC2 and not printed.

9. EC2 metadata abuse
   Threat: Container or process tries to access EC2 metadata insecurely.
   Mitigation: Terraform enforces IMDSv2 using http_tokens = required.

10. Cost abuse
    Threat: Paid resources are accidentally created.
    Mitigation: Terraform removes NAT Gateway, ALB, ECS Fargate, RDS, Secrets Manager, and WAF from live deployment. ECR lifecycle policy keeps only 5 images.
